# 계란 잘 까지는 법 — 속설 조사와 실험 설계 (2026-10-11)

## 사람들이 궁금해하는 것 / 흔한 답
| 속설 | 흔한 설명 | 근거 수준 |
|---|---|---|
| 식초 넣고 삶기 | 껍질 탄산칼슘을 녹여 잘 까짐 | 약~중: 식품과학 교수 코멘트(칼슘 일부 용해), 비공식 4개 비교에서 식초 최고(The Takeout). 국내 커뮤니티엔 "별 효과 없음" 후기도 |
| 소금 넣고 삶기 | 막을 느슨하게 함 | 약: 근거 없음. 비교 테스트에서 맹물과 비슷 |
| 삶은 직후 찬물·얼음물 | 속이 수축해 막과 흰자 사이 틈 | 중: 가장 많이 반복되는 조언 |
| 끓는 물에 넣고 시작 | 흰자 바깥이 빨리 굳어 막에 덜 붙음 | 중~강: America's Test Kitchen 5가지 방법 비교(방법당 10개)에서 끓는물·찜이 가장 깔끔 |
| 오래된 계란 | 시간이 지나 흰자가 막과 덜 붙음 | 중: 널리 인정되지만 통제실험 자료는 이번 조사에선 미확인 |
| 상온에 뒀다 삶기 | 차가운 계란은 막에 더 붙음 | 약: 칼럼 주장 |
| 베이킹소다 | pH↑로 잘 까짐 | 약: 출처끼리 엇갈림 |

## 실험 설계 (확정: 계란 2개 — 흔한 방법 vs 내 방법)
| | ① 흔한 방법 | ② 내 방법(사용자가 매일 쓰는 방식) |
|---|---|---|
| 시작 | 찬물에 계란 넣고 같이 끓이기 | 냄비에 찬물(계란 4/5 잠길 양) → 끓으면 계란 넣기(국자로 천천히) |
| 첨가 | 식초 + 소금 | 없음 |
| 시간 | 끓고 10분 | 10분 |
| 식히기 | 그냥 꺼내 식힘 | 미리 수돗물 받아둔 큰 그릇에 계란만 옮기고 수돗물 틀어 1~2분 (얼음 없음) |
- 같은 날 산 계란, 매직으로 ①② 표시, 같은 손·같은 방식으로 깜.
- 확인: 뚜껑 여부(4/5만 잠기므로 뚜껑 없으면 윗부분 덜 익을 수 있음).
- 한계(문구에 반영): 시작온도·첨가물·식히기가 동시에 달라 원인 하나로 단정 불가 → "식초가 효과 없다"가 아니라 "이 방법이 더 잘 까졌다"로 표현.

### 촬영 (세로)
1. 계란 2개에 ①② 쓰기 2. ① 찬물에 식초·소금 넣기 3. ② 끓는 물에 넣기 4. ② 수돗물 그릇으로 옮기기 5. 둘 다 까는 장면(핵심) 6. 깐 계란 2개 나란히 사진
- 편집: 첫 장면은 결과(깐 계란 2개 나란히)로 시작.
### 기록
- 까는 데 걸린 시간(초), 흰자 뜯긴 정도(0~3)

## 문구 방향 (결과별)
- ②가 잘 까짐 → "식초·소금 넣을 시간에 이렇게 해봐 ㅋㅋ 매일 이렇게 깜"
- 둘 다 비슷 → "결국 계란 신선도가 범인?" → 다음 실험 예고
- ①이 더 잘 까짐 → 솔직하게 "식초 무시했는데 미안 ㅋㅋ"
- 게시: 컵 흔들기(일) 3~4일 뒤, "계란 2탄"으로 연결.
