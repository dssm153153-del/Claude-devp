## v2 기획: 원본 구성 따라가기 (사용자: "원본같이", 정적 카메라 접근 장면은 별로)
### 원본 재분석 (ref/Src.mp4, 7초, 3컷: 3.47 / 5.37)
- S1 0–3.47: 주인 시점 하이앵글 핸드헬드로 걷는 강아지를 따라감. 따뜻한 조명의 야간 광장 보도블록, 화면 위쪽에 지나가는 사람들 다리·발(멈춰서 쳐다봄 = "시선집중"). 날개가 걸음마다 출렁임.
- S2 3.47–5.37: 쪼그려 앉은 여성(머리카락에 얼굴 가려짐)에게 강아지가 두 발로 서서 안김 → 들어 올림. 5.0–5.37 빠른 움직임.
- S3 5.37–7.0: 여성이 강아지를 안고 볼에 뽀뽀, 날개 활짝, 뒤로 도시 야경 보케. 핸드헬드.
- 자막 "요정 날개 하나로 지나가는 사람마다 시선집중!" 상단 고정.
- 내 v1이 별로인 이유: 고정 카메라·빈 산책로·사람 없음 → 원본의 생동감(따라가는 카메라), 사회적 증거(쳐다보는 사람들), 애정(안기·뽀뽀)이 다 빠짐.
### 새 구성 (3클립, 모두 Kling O1 Start/End, 같은 강아지·같은 주인)
- K1 따라가기: 하이앵글 핸드헬드, 광장을 종종걸음, 뒤에 멈춰 보는 사람들 다리.
- K2 안기기: 쪼그려 앉은 주인에게 달려와 두 발로 안김.
- K3 안고 뽀뽀: 주인이 안고 볼 비빔, 날개 빛, 야경 보케.
- 주인 얼굴은 항상 머리카락·강아지로 가림. 원본 옷(검정 크롭티)은 따라 하지 않고 베이지 후드+청바지.
- 상품 날개는 원본보다 작은 레이스 날개 → 클로즈업과 LED 빛으로 보완. 자막은 우리 문구로 상단에.
- K1-Start.png(941x1672): 통과. 하이앵글 주인 시점, 같은 강아지·레이스 날개 LED, 뒤에 멈춘 행인 3명 다리(얼굴 없음), 간판·글자 없음, 강아지가 혀 내밀고 올려다봄.
- K1-End.png: 통과(조건부). 강아지가 행인 쪽으로 이동·뒷모습, 날개 LED 동일, 행인 쪼그려 손 내밂(얼굴 없음). 손: 손가락 4개 끝이 보이고 엄지는 손바닥 뒤로 가려진 각도 → 영상에서 손가락 수 재확인.
- K1.mp4(압축본 1080x1916, 10초): 통과. 0–4.5초 강아지가 혀 내밀고 카메라 쪽으로 종종걸음(가장 좋음) → 4.5–7초 옆으로 돌아 걸음(날개 옆모습, 덜 예쁨) → 7.5–10초 행인 손 냄새 맡음(손 정상). 끝 튐 없음. 편집 때 4.5–7초는 배속 압축.
