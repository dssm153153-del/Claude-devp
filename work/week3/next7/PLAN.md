# 3주차 후보: 마스카라 바를 때 입 벌어지는 커플 (3D 애니)

## 원본 (ref/Src.mp4)
- 480x864, 24fps, 16.4초, 소리 있음. 픽사풍 3D AI 애니메이션. 욕실 거울에 비친 구도(거울 속 시점).
- 컷: 0–11.5 거울 클로즈업 / 11.5–16.4 거울 테두리·세면대까지 보이는 넓은 샷.

| 시간 | 장면(화면 기준) |
|---|---|
| 0–2.0 | 여자가 마스카라 바르며 입 "아" 벌림. 뒤에서 남자 등장 |
| 2.0–3.0 | 남자도 마스카라 들고 같이 입 벌리고 따라 바름 |
| 3.0–4.5 | 여자가 눈치채고 입 닫음, 고개 숙여 마스카라 만지작. 남자는 씩 웃음 |
| 4.5–8.5 | 여자가 마스카라 솔을 입 쪽·코밑에 대고 이상한 동작(콧수염처럼 가로로 댐) |
| 8.5–11.5 | 남자는 마스카라 쥔 채 놀란 얼굴로 지켜봄 |
| 11.5–14.0 | 넓은 샷: 여자가 째려봄, 남자가 손가락으로 자기 얼굴 가리키며 변명 |
| 14.0–16.4 | 여자가 다시 입 "오" 벌리고 마스카라, 남자 멍하니 봄 |

- 소리: 거의 전 구간 낮은 음(80–100Hz)의 말소리/음악, 11.5–14 음정 없는 큰 소리(효과음·음악 추정). 내용은 사용자 청취 확인 필요.
