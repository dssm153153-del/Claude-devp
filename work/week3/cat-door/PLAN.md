# 3주차 새 컨셉 1호: 문 여는 고양이

- 아이디어: 고양이가 점프해 문고리(레버)에 매달리고, 체중으로 손잡이를 눌러 문을 열고 나간다. 사용자 제공 이미지 images/Idea-ref.png.
- 3가지 기준: 첫 1초 ○(매달린 고양이) / 설명 불필요 ○ / 한마디 하고 싶어짐 ○("우리 집 애도 함", "문고리 세로로 바꿔야 함")
- 2단계 홍보 연결: 레버 손잡이 잠금장치(반려동물·유아용) → "고양이가 문 여는 거 막는 법 찾아봄".
- 톤: 영화 같은 금빛 먼지 연출 X → 집에서 폰/홈캠으로 찍은 평범한 실내(가짜 리얼처럼 "우리 집 고양이"라고 주장하지 않음, 쓰레드 AI 라벨 사용).
- 제작: Kling 2.5(무제한, 시작 이미지만). 점프-매달림-문 열림-나감을 한 번에 시키면 깨질 위험 → 시작 이미지를 "이미 손잡이에 매달린 순간"으로 하고, 영상은 손잡이가 내려감 → 문이 살짝 열림 → 고양이 착지 후 틈으로 나감(5초).
- 글: 질문 금지, 한 장면 + 반응 한 줄.
