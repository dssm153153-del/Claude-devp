# 3주차 새 컨셉 1호: 문 여는 고양이

- 아이디어: 고양이가 점프해 문고리(레버)에 매달리고, 체중으로 손잡이를 눌러 문을 열고 나간다. 사용자 제공 이미지 images/Idea-ref.png.
- 3가지 기준: 첫 1초 ○(매달린 고양이) / 설명 불필요 ○ / 한마디 하고 싶어짐 ○("우리 집 애도 함", "문고리 세로로 바꿔야 함")
- 2단계 홍보 연결: 레버 손잡이 잠금장치(반려동물·유아용) → "고양이가 문 여는 거 막는 법 찾아봄".
- 톤: 영화 같은 금빛 먼지 연출 X → 집에서 폰/홈캠으로 찍은 평범한 실내(가짜 리얼처럼 "우리 집 고양이"라고 주장하지 않음, 쓰레드 AI 라벨 사용).
- 제작: Kling 2.5(무제한, 시작 이미지만). 점프-매달림-문 열림-나감을 한 번에 시키면 깨질 위험 → 시작 이미지를 "이미 손잡이에 매달린 순간"으로 하고, 영상은 손잡이가 내려감 → 문이 살짝 열림 → 고양이 착지 후 틈으로 나감(5초).
- 글: 질문 금지, 한 장면 + 반응 한 줄.

## 진행
- Cat-Start.png(1086x1448): 통과. 실제 폰 사진 느낌, 앞발 2개 손잡이 잡음, 뒷다리 2개+꼬리 정상. 약점: 고개를 뒤로 젖혀 얼굴이 잘 안 읽히고 아래쪽 귀가 턱처럼 보임 → 영상에서 얼굴이 뭉개지면 재생성.
- ~~Kling 2.5 시작 이미지만~~ → 사용자 지적으로 철회: 스킬 기준은 Start/End 방식. 문고리·문·착지처럼 여러 단계 물리 동작을 Start만 주면 모델이 지어낸다.
- 변경: Cat-End.png(Cat-Start 편집: 같은 집·구도, 문 25cm 열림, 손잡이 수평 복귀, 고양이 바닥 착지 후 머리·앞몸이 틈으로 들어감) → Kling O1 Start/End 5초 → Cat-K1.mp4. 실패 시 중간 키프레임(손잡이 눌림·문 살짝 열림·아직 매달림)으로 K1a/K1b 분할.
- Cat-End.png: 통과. 차이 마스크상 신발장·바닥·문틀 일치, 변화는 문·고양이만. 손잡이 수평 복귀, 문 틈 열림, 뒷다리 2+꼬리 정상.
- Cat-K1(Kling O1 Start/End 5초, 1244x1660 24fps 5.08초): **불합격**. 0–1.3초 고양이가 매달려 버둥거리기만 하고 손잡이는 끝까지 수평(안 눌림). 1.5초쯤 그냥 떨어져 문을 앞발로 긁다가 2.6초부터 문이 저절로 열리고 들어감 → 핵심(체중으로 손잡이 눌러 열기)이 빠짐. 꼬리가 중간부터 줄무늬로 바뀜.
- 원인: 스카프 매듭과 같은 "소품 상태 변화"(손잡이 회전→걸쇠 풀림)는 Start/End 사이에서 모델이 생략. 끝 이미지 손잡이가 수평이라 "눌린 손잡이" 상태가 어디에도 없음.
- 해결: 중간 키프레임 Cat-Mid.png(손잡이 45° 눌림, 고양이 몸 손잡이 따라 내려감, 문 3~5cm 열림) → K1a(Start→Mid, 3초) + K1b(Mid→End, 5초).
