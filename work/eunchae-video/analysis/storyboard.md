# 스토리보드 (v2)

> 목적: 쿠팡 판매 상품(작약 실크 스카프)의 실제 사용 영상. 원본 영상의 묶는 법·동작은 그대로, 인물은 한국 여성, 스카프는 실제 상품으로 교체. 상품 무늬·색이 실제와 같아야 한다(검수 1순위).

## 변경 사항 (v2: 스틸컷 Style-ref-A/B 기준 최종안)
- 인물: 20~30대 한국 여성, 어깨 아래 길이의 짙은 갈색 웨이브 머리, MLBB 립. 프레임 위 끝은 코 아래(Style-ref-B처럼 입술·턱만 보임). 전 컷 동일, 완성샷도 같은 크롭.
- 의상(확정: Style-ref-A): 모카 브라운 긴팔 니트(Style-ref-A), 크루넥. 소매는 팔뚝 중간까지 걷어 올려 손목을 비운다(손목에 감는 트릭 때문). 얇은 금 체인 + 작은 금 코인 펜던트 목걸이(두 스틸 공통). 팔찌 없음(C1 포즈에서 팔찌 지시가 손목 중복 결함을 만들어 제거). 가방 없음(팔 동작 방해).
- 스카프: Style-ref-A/B의 실크 정사각 스카프(상품 사양: 천연 실크, 90x90cm, 대각선 약 127cm → 원본 스키니 스카프 길이 약 1.2m와 비슷). 흰 바탕에 빨강·핑크 작약과 들꽃, 녹색 잎, 라일락 그레이 테두리. 대각선으로 접어 폭 약 6cm의 긴 띠로 만들어 쓴다(양쪽 가장자리에 라일락 테두리 선이 보임 → 원본의 청록 테두리 역할). Scarf-ref(백합 원단)는 사용하지 않는다.
- 배경: 밝은 파리풍 카페 실내, 크림색 벽과 창이 얕은 심도로 흐리게 보임. 따뜻한 자연광. 카메라 정면 가슴 높이 고정.
