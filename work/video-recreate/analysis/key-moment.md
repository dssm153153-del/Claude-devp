# 핵심 구간 정밀 분석 (사용자 제공 프레임 91장 = 원본 9.5~12.5초, 매 프레임)

| 원본 시간 | 동작 |
|---|---|
| 9.5–9.9 | 문 밖 로비에서 정면을 보고 걸어옴, 고개를 숙여 바닥을 봄. 팔은 내려옴 |
| 10.0–10.1 | 문턱 직전에서 멈춤. 왼팔을 뒤로 번쩍 쳐들고 몸을 뒤로 젖힘(경악). 발은 로비 쪽 |
| 10.15–10.3 | 오른손이 문 옆 세로 황동 손잡이를 낚아챔. 왼팔은 머리 위에서 휘저음. 몸이 뒤-왼쪽으로 기움 |
| 10.33–10.5 | 무릎이 꺾이며 몸이 아래로 주저앉음. 상체가 손잡이(화면 왼쪽 아래) 쪽으로 쏠림 |
| 10.6–11.0 | 상체가 거의 수평으로 낮게 엎어지며 문틀 왼쪽 모서리(손잡이·버튼 패널)에 매달림. 오른손은 손잡이 아래쪽을 잡고, 왼손은 칸 안 왼쪽 아래로 뻗어 버팀. 엉덩이는 문턱 위, 다리는 로비 쪽에 남고 왼다리를 뒤로 굽혀 차올림. 머리는 버튼 패널 옆 |
| 11.1– | 인서트(포스터 풀샷) |

결론: 발은 절대 포스터를 밟지 않는다. 앞으로 쏠리는 몸을 손잡이로 붙잡아 '안 빠지려고' 매달리는 동작이다. 최종 자세는 서서 다리를 드는 게 아니라 문틀 왼쪽 아래 모서리로 낮게 엎어져 매달리는 자세다.
